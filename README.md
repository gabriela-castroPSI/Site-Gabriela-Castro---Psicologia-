# Site — Gabriela Castro | Psicologia

Site institucional da psicóloga Gabriela Castro (atendimento online, abordagem fenomenológico-existencial).

## 🌐 Acessar o site

**https://gabrielamarianocastropsi.com.br**

(GitHub Pages: https://gabriela-castropsi.github.io/Site-Gabriela-Castro---Psicologia-/)

## Sobre o projeto

Site estático hospedado no GitHub Pages, publicado automaticamente a partir da branch `main`. Domínio próprio configurado via arquivo `CNAME`.

| Arquivo | Descrição |
| --- | --- |
| `index.html` | Página principal |
| `politica-de-privacidade.html` | Política de Privacidade (LGPD + Google Ads) |
| `styles.css` | Estilos do site |
| `assets/` | Imagens e demais recursos |
